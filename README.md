# Porco Aranha

Isso é de ago/2023, da época da faculdade. Coloquei no GitHub em 2026 como registro e deixei como estava.

Projeto em Construct 3 de agosto de 2023. Tem um menu (start, options e exit), uma tela de opções com volume e modo para daltônicos, e uma cena em que os personagens andam com as setas do teclado.

## Como abrir

Arraste o `PorcoAranhaConstruct.c3p` pra dentro do Construct 3 no navegador (editor.construct.net). A pasta `PorcoAranhaConstruct` é o mesmo projeto descompactado, pra dar pra ver os arquivos aqui no GitHub.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
